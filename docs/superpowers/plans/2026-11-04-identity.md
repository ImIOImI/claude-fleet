**Architecture:**
- Everything identity-related lives in `src/main/identity/` and has **no Electron imports**. A guard test enforces this.

  - `IdentityService` takes its vault and client-id resolver by injection.
  - `ipc.ts` wires the real vault, the `identity:*` channels and the loadout hook.
- The token lives in the safeStorage vault under the reserved, renderer-unreadable scope `identity:github`, with keys `TOKEN` and `PROFILE`. The renderer only ever sees `AccountStatus`.

**Tech Stack:** Electron main (Node 22 global `fetch`), TypeScript strict ESM (`.js` import suffixes), vitest (unit), React renderer, Playwright (e2e, CI only).

## Global Constraints

- **No Electron in `src/main/identity/`.** No module there may import `electron`, `../vault.js`, `../config.js` or `../ipc.js`. Allowed imports:
  - siblings in `src/main/identity/`;
  - `../vaultScopes.js` (pure);
  - type-only `../../preload/identityTypes.js`;
  - `node:*` builtins.

  Task 4's guard test enforces this.
- **Identity shape** (exact): `{ provider, kind: 'user' | 'machine', login, id: number, name: string | null, avatarUrl: string | null, teams: string[] }`. Teams are `'org/team-slug'`, lower-cased and sorted. **The display name is the profile `name` when it isn't blank, otherwise the `login`** (`displayName()`).
- **OAuth scopes requested** (exact): `read:org read:packages`. These were verified against GitHub docs on 2026-11-04:
  - *Scopes for OAuth apps*: "(no scope)" already grants "read-only access to public information (including user profile info)". That covers `GET /user` login, id, name and avatar_url, so `read:user` is **not** needed.
  - `read:org` is required by `GET /user/teams`.
  - `read:packages` "grants access to download or install packages from GitHub Packages" (GHCR pulls).

  The design spec's `read:user read:org` is corrected in Task 12.
- **Device flow** (GitHub docs, *Authorizing OAuth apps → Device flow*):
  - `POST https://github.com/login/device/code` with `client_id` and `scope`.
  - Poll `POST https://github.com/login/oauth/access_token` with `client_id`, `device_code` and `grant_type=urn:ietf:params:oauth:grant-type:device_code`.
  - Send `Accept: application/json`. No client secret.
  - Errors: `authorization_pending`, `slow_down` (+5 s to the interval), `expired_token`, `access_denied`, `device_flow_disabled`, `incorrect_client_credentials`, `incorrect_device_code`, `unsupported_grant_type`.
- **Hosts:** GitHub requests go only to `https://github.com` (device flow) and `https://api.github.com` (REST/GraphQL). A pagination `Link` pointing anywhere else is not followed. A `verification_uri` or SSO URL that isn't `https://github.com/...` is replaced or dropped.
- **The token never reaches the renderer, a log line or an error message.** That covers every `identity:*` response, `AccountStatus`, `SignInStart` and `SignInPoll`. The device code also stays in main.
- **Vault:** scope `identity:github` (`GITHUB_IDENTITY_SCOPE`), keys `TOKEN` and `PROFILE`. `identity:` is added to `RESERVED_VAULT_PREFIXES` and refused by `assertRendererVaultScope`. Sign-out purges the whole scope.
- **Degraded vault** (`isVaultAvailable()` false): the sign-in is kept in main-process memory for this run only, and `AccountStatus.persisted` is `false`.
- **Client id resolution** (first valid wins): env `CLAUDE_FLEET_GITHUB_CLIENT_ID`, then `config.json` `identity.github.clientId`, then the built-in `BUILTIN_GITHUB_CLIENT_ID`, which is `''` until the owner action. With none, `identity:signInStart` throws `not-configured: GitHub sign-in isn't configured: no OAuth client id. Set CLAUDE_FLEET_GITHUB_CLIENT_ID or identity.github.clientId in config.json.` **Never invent a real client id**; tests use `Iv1.testclient` or `Iv1.e2eplaceholder`.
- **Grants:**
  - Tiers are cumulative: `read` < `steer` < `session`.
  - A person's tier is the highest tier any rule grants (team or login, compared case-insensitively). No match means `null` (no access).
  - Machines get a tier only from `machines` rules (by login). User rules never match a machine.
- **Machines:** a GitHub App installation token gets a 403 "Resource not accessible by integration" from `GET /user`. The provider then:
  1. asks GraphQL `viewer { __typename login ... on Bot { databaseId } }`;
  2. resolves the slug's app id with `GET /apps/<slug>`;
  3. maps it to a configured `{ appId, login, tier }`.

  The identity's `login` is the **configured** login.
- **Verify cache:** successful `verify` results are cached for 5 minutes, keyed by the token's SHA-256. Failures aren't cached.
- **Loadout hook:** `loadoutSources.setGithubTokenProvider(() => identity.packagesToken())`. It returns the token only when the saved scopes include `read:packages` or `write:packages`, and it's never offered to `DEFAULT_SOURCES` (public: a revoked token must not break the default catalog).
- **Out of scope:** OIDC/Entra (only the `IdentityProvider` seam), `RemoteClient`, `/whoami`, host config loading (sub-project c), server-side token revocation (it needs the client secret, so sign-out is local plus a link to GitHub's Authorized OAuth Apps page).
- `.claude/rules/spec-maintenance.md`: this adds IPC channels, a vault scope, a config key, a user flow and security rules, so `docs/SPEC.md` is updated in the same PR (Task 12). It squash-merges into one commit.

// Identity-provider seam (remote-workspaces §5, sub-project (b)). Pure — no
// electron — so fleet-host (sub-project (c)) imports it unchanged. GitHub is
// the first provider (githubProvider.ts); OIDC (e.g. Entra ID) is a later
// second implementation of the same IdentityProvider interface: verify an ID
// token against the issuer's JWKS, map groups to `teams`.

export type IdentityKind = 'user' | 'machine';

export interface Identity {
  /** Id of the provider that verified this identity, e.g. 'github'. */
  provider: string;
  kind: IdentityKind;
  /** For machines: the bot login configured in the host's `machines` rules. */
  login: string;
  /** Provider's numeric account id (GitHub user id, or the bot user's id). */
  id: number;
  /** Profile display name; null when unset. Render with displayName(). */
  name: string | null;
  avatarUrl: string | null;
  /** 'org/team-slug', lower-cased and sorted. Always empty for machines. */
  teams: string[];
}

export interface IdentityProvider {
  readonly id: string;
  /** Verify a bearer token and say who it belongs to. Throws IdentityError. */
  verify(token: string): Promise<Identity>;
}

export type IdentityErrorKind = 'unauthorized' | 'machine-unknown' | 'network' | 'upstream';

/** Messages never contain the token. */
export class IdentityError extends Error {
  readonly kind: IdentityErrorKind;
  readonly status?: number;
  constructor(kind: IdentityErrorKind, message: string, status?: number) {
    super(message);
    this.name = 'IdentityError';
    this.kind = kind;
    this.status = status;
  }
}

/** The profile name, or the login when the name is unset or blank. */
export function displayName(i: Pick<Identity, 'name' | 'login'>): string {
  const n = i.name?.trim();
  return n ? n : i.login;
}

```ts
// Grant tiers (remote-workspaces §5). Pure: fleet-host (sub-project (c)) maps a
// verified Identity plus its deployment's grant rules to a tier, and checks
// each route/frame with tierAtLeast. No match means no access (403).

import type { Identity } from './types.js';

export type Tier = 'read' | 'steer' | 'session';
/** Cumulative, lowest first. */
export const TIERS: readonly Tier[] = ['read', 'steer', 'session'];

export type GrantRule = { team: string; tier: Tier } | { login: string; tier: Tier };
export interface MachineRule {
  appId: number;
  login: string;
  tier: Tier;
}
export interface GrantConfig {
  grants: GrantRule[];
  machines: MachineRule[];
}

const rank = (t: Tier): number => TIERS.indexOf(t);
const lc = (s: string): string => s.toLowerCase();

export function tierAtLeast(have: Tier | null, need: Tier): boolean {
  return have !== null && rank(have) >= rank(need);
}

function higher(a: Tier | null, b: Tier): Tier {
  return a === null || rank(b) > rank(a) ? b : a;
}

/**
 * The highest tier any matching rule grants, or null (no access). People match
 * `grants` by team or login; machines match only `machines` by login — a
 * user-shaped rule never admits a machine, and vice versa.
 */
export function resolveTier(who: Pick<Identity, 'kind' | 'login' | 'teams'>, config: GrantConfig): Tier | null {
  const login = lc(who.login);
  let best: Tier | null = null;
  if (who.kind === 'machine') {
    for (const m of config.machines) if (lc(m.login) === login) best = higher(best, m.tier);
    return best;
  }
  const teams = new Set(who.teams.map(lc));
  for (const g of config.grants) {
    const hit = 'team' in g ? teams.has(lc(g.team)) : lc(g.login) === login;
    if (hit) best = higher(best, g.tier);
  }
  return best;
}

export class GrantConfigError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'GrantConfigError';
  }
}

const TEAM_RE = /^[A-Za-z0-9-]+\/[A-Za-z0-9._-]+$/;
const LOGIN_RE = /^[A-Za-z0-9-]+$/;
const BOT_RE = /^[A-Za-z0-9-]+\[bot\]$/;

function parseTier(v: unknown, path: string): Tier {
  if (v === 'read' || v === 'steer' || v === 'session') return v;
  throw new GrantConfigError(`${path}.tier must be one of read, steer, session`);
}

function asRecord(v: unknown, path: string): Record<string, unknown> {
  if (!v || typeof v !== 'object' || Array.isArray(v)) throw new GrantConfigError(`${path} must be an object`);
  return v as Record<string, unknown>;
}

/**
 * Validate deployment-provided grant config (host config YAML, already parsed).
 * Throws GrantConfigError naming the offending path. Unknown keys are ignored
 * so the same object can carry `identity: {...}` and other host settings.
 */
export function parseGrantConfig(raw: unknown): GrantConfig {
  if (!raw || typeof raw !== 'object' || Array.isArray(raw)) throw new GrantConfigError('grant config must be an object');
  const o = raw as Record<string, unknown>;
  const list = (k: string): unknown[] => {
    const v = o[k];
    if (v === undefined) return [];
    if (!Array.isArray(v)) throw new GrantConfigError(`${k} must be a list`);
    return v;
  };

  const grants = list('grants').map((g, i): GrantRule => {
    const p = `grants[${i}]`;
    const r = asRecord(g, p);
    const hasTeam = 'team' in r;
    const hasLogin = 'login' in r;
    if (hasTeam === hasLogin) throw new GrantConfigError(`${p} needs exactly one of team or login`);
    const tier = parseTier(r.tier, p);
    if (hasTeam) {
      if (typeof r.team !== 'string' || !TEAM_RE.test(r.team)) {
        throw new GrantConfigError(`${p}.team must look like org/team-slug`);
      }
      return { team: r.team, tier };
    }
    if (typeof r.login !== 'string' || !LOGIN_RE.test(r.login)) {
      throw new GrantConfigError(`${p}.login must be a GitHub login`);
    }
    return { login: r.login, tier };
  });

  const seen = new Set<number>();
  const machines = list('machines').map((m, i): MachineRule => {
    const p = `machines[${i}]`;
    const r = asRecord(m, p);
    if (typeof r.appId !== 'number' || !Number.isInteger(r.appId) || r.appId <= 0) {
      throw new GrantConfigError(`${p}.appId must be a positive integer`);
    }
    if (typeof r.login !== 'string' || !BOT_RE.test(r.login)) {
      throw new GrantConfigError(`${p}.login must be a bot login ending in [bot]`);
    }
    if (seen.has(r.appId)) throw new GrantConfigError(`machines: appId ${r.appId} listed twice`);
    seen.add(r.appId);
    return { appId: r.appId, login: r.login, tier: parseTier(r.tier, p) };
  });

  return { grants, machines };
}
```

// Pure parsers for the GitHub response headers identity depends on. Kept apart
// from githubProvider.ts so they unit-test without a fetch stub.

export const GITHUB_API = 'https://api.github.com';

/** What an X-GitHub-SSO header told us (SAML SSO orgs, remote-workspaces §5). */
export interface SsoHint {
  /** `required; url=…`: the org-specific authorise URL (https://github.com only). */
  url: string | null;
  /** Org login parsed from that URL's `/orgs/<org>/sso` path. */
  org: string | null;
  /** `partial-results; organizations=…`: ids of orgs that withheld results. */
  orgIds: number[];
}

export function parseScopes(header: string | null): string[] {
  if (!header) return [];
  return header
    .split(',')
    .map((s) => s.trim())
    .filter(Boolean);
}

/** Can this token pull from GHCR? write:packages includes read:packages. */
export function hasPackagesRead(scopes: readonly string[]): boolean {
  return scopes.some((s) => s === 'read:packages' || s === 'write:packages');
}

function githubUrl(raw: string): URL | null {
  try {
    const u = new URL(raw);
    return u.protocol === 'https:' && u.hostname === 'github.com' ? u : null;
  } catch {
    return null;
  }
}

export function parseSsoHeader(header: string | null): SsoHint | null {
  if (!header) return null;
  const rawUrl = /(?:^|;)\s*url=([^;\s]+)/.exec(header)?.[1] ?? null;
  const rawIds = /(?:^|;)\s*organizations=([\d,\s]+)/.exec(header)?.[1];
  const orgIds = rawIds
    ? rawIds
        .split(',')
        .map((s) => Number(s.trim()))
        .filter((n) => Number.isInteger(n) && n > 0)
    : [];
  const u = rawUrl ? githubUrl(rawUrl) : null;
  if (!u && orgIds.length === 0) return null;
  return {
    url: u ? u.toString() : null,
    org: u ? (/^\/orgs\/([^/]+)\/sso/.exec(u.pathname)?.[1] ?? null) : null,
    orgIds
  };
}

export function mergeSso(a: SsoHint | null, b: SsoHint | null): SsoHint | null {
  if (!a) return b;
  if (!b) return a;
  return {
    url: a.url ?? b.url,
    org: a.org ?? b.org,
    orgIds: [...new Set([...a.orgIds, ...b.orgIds])].sort((x, y) => x - y)
  };
}

/** The rel="next" URL of a Link header, but only on api.github.com (the token
 *  rides along, so a foreign next link is never followed). */
export function nextLink(header: string | null): string | null {
  if (!header) return null;
  for (const part of header.split(',')) {
    const m = /<([^>]+)>\s*;\s*rel="next"/.exec(part);
    if (m) return m[1].startsWith(`${GITHUB_API}/`) ? m[1] : null;
  }
  return null;
}

```ts
// The `github` IdentityProvider (remote-workspaces §5). Pure — global fetch
// only — so fleet-host reuses it. Two entry points:
//  - probe(token): desktop sign-in. User tokens only: identity + granted
//    scopes (X-OAuth-Scopes) + any SAML SSO hint (X-GitHub-SSO).
//  - verify(token): the host's per-request check. A user, or a GitHub App
//    installation token mapped to a configured machine rule.
// Every request goes to api.github.com; error messages never carry the token.

import type { Identity, IdentityProvider } from './types.js';
import { IdentityError } from './types.js';
import type { MachineRule } from './grants.js';
import { GITHUB_API, mergeSso, nextLink, parseScopes, parseSsoHeader, type SsoHint } from './githubHeaders.js';

export interface GithubProbe {
  identity: Identity;
  scopes: string[];
  sso: SsoHint | null;
}

export interface GithubProvider extends IdentityProvider {
  probe(token: string): Promise<GithubProbe>;
}

const MAX_TEAM_PAGES = 10;
const INTEGRATION_MSG = 'Resource not accessible by integration';
const VIEWER_QUERY = 'query { viewer { __typename login ... on Bot { databaseId } } }';

function headers(token: string): Record<string, string> {
  return {
    Accept: 'application/vnd.github+json',
    Authorization: `Bearer ${token}`,
    'X-GitHub-Api-Version': '2022-11-28',
    'User-Agent': 'claude-fleet'
  };
}

async function ghFetch(url: string, init: { method?: string; headers: Record<string, string>; body?: string }): Promise<Response> {
  try {
    return await fetch(url, init);
  } catch (err) {
    throw new IdentityError('network', `GitHub unreachable (${(err as Error).name})`);
  }
}

async function readJson(res: Response): Promise<unknown> {
  try {
    return await res.json();
  } catch {
    return null;
  }
}

function message(body: unknown): string {
  return body && typeof body === 'object' && typeof (body as { message?: unknown }).message === 'string'
    ? (body as { message: string }).message
    : '';
}

interface GhUser {
  login: string;
  id: number;
  name?: unknown;
  avatar_url?: unknown;
}
function isGhUser(v: unknown): v is GhUser {
  return !!v && typeof v === 'object' && typeof (v as GhUser).login === 'string' && typeof (v as GhUser).id === 'number';
}

async function fetchTeams(token: string): Promise<{ teams: string[]; sso: SsoHint | null }> {
  const teams = new Set<string>();
  let sso: SsoHint | null = null;
  let url: string | null = `${GITHUB_API}/user/teams?per_page=100`;
  for (let page = 0; url && page < MAX_TEAM_PAGES; page++) {
    const res = await ghFetch(url, { headers: headers(token) });
    sso = mergeSso(sso, parseSsoHeader(res.headers.get('x-github-sso')));
    // 403 without read:org, or SAML-protected: teams stay partial, sso says why.
    if (!res.ok) break;
    const body = await readJson(res);
    if (!Array.isArray(body)) break;
    for (const t of body as Array<{ slug?: unknown; organization?: { login?: unknown } } | null>) {
      const slug = t?.slug;
      const org = t?.organization?.login;
      if (typeof slug === 'string' && typeof org === 'string') teams.add(`${org}/${slug}`.toLowerCase());
    }
    url = nextLink(res.headers.get('link'));
  }
  return { teams: [...teams].sort(), sso };
}

type UserResult = { kind: 'user'; probe: GithubProbe } | { kind: 'integration' };

async function fetchUser(token: string): Promise<UserResult> {
  const res = await ghFetch(`${GITHUB_API}/user`, { headers: headers(token) });
  if (res.status === 401) throw new IdentityError('unauthorized', 'GitHub rejected the token', 401);
  if (res.status === 403) {
    const msg = message(await readJson(res));
    if (msg.includes(INTEGRATION_MSG)) return { kind: 'integration' };
    throw new IdentityError('upstream', `GitHub GET /user answered 403${msg ? `: ${msg}` : ''}`, 403);
  }
  if (!res.ok) throw new IdentityError('upstream', `GitHub GET /user answered HTTP ${res.status}`, res.status);
  const u = await readJson(res);
  if (!isGhUser(u)) throw new IdentityError('upstream', 'GitHub GET /user returned an unexpected body');
  const scopes = parseScopes(res.headers.get('x-oauth-scopes'));
  const userSso = parseSsoHeader(res.headers.get('x-github-sso'));
  const { teams, sso } = await fetchTeams(token);
  const name = typeof u.name === 'string' && u.name.trim() ? u.name : null;
  return {
    kind: 'user',
    probe: {
      identity: {
        provider: 'github',
        kind: 'user',
        login: u.login,
        id: u.id,
        name,
        avatarUrl: typeof u.avatar_url === 'string' ? u.avatar_url : null,
        teams
      },
      scopes,
      sso: mergeSso(userSso, sso)
    }
  };
}

async function verifyMachine(token: string, machines: readonly MachineRule[]): Promise<Identity> {
  const res = await ghFetch(`${GITHUB_API}/graphql`, {
    method: 'POST',
    headers: { ...headers(token), 'Content-Type': 'application/json' },
    body: JSON.stringify({ query: VIEWER_QUERY })
  });
  if (res.status === 401) throw new IdentityError('unauthorized', 'GitHub rejected the token', 401);
  if (!res.ok) throw new IdentityError('upstream', `GitHub GraphQL answered HTTP ${res.status}`, res.status);
  const body = (await readJson(res)) as { data?: { viewer?: { __typename?: unknown; login?: unknown; databaseId?: unknown } } } | null;
  const v = body?.data?.viewer;
  if (!v || v.__typename !== 'Bot' || typeof v.login !== 'string' || typeof v.databaseId !== 'number') {
    throw new IdentityError('upstream', 'GitHub GraphQL viewer is not a bot');
  }
  const slug = v.login.replace(/\[bot\]$/, '');
  if (!/^[A-Za-z0-9-]+$/.test(slug)) throw new IdentityError('upstream', 'GitHub returned an unexpected bot login');
  const appRes = await ghFetch(`${GITHUB_API}/apps/${slug}`, { headers: headers(token) });
  if (!appRes.ok) throw new IdentityError('upstream', `GitHub GET /apps/${slug} answered HTTP ${appRes.status}`, appRes.status);
  const app = (await readJson(appRes)) as { id?: unknown } | null;
  const rawId = app ? app.id : undefined;
  const appId = typeof rawId === 'number' ? rawId : null;

  const rule = machines.find((m) => m.appId === appId);
  if (!rule) throw new IdentityError('machine-unknown', `GitHub App ${slug} (id ${appId}) is not a configured machine`);
  return { provider: 'github', kind: 'machine', login: rule.login, id: v.databaseId, name: null, avatarUrl: null, teams: [] };
}

export function createGithubProvider(opts: { machines?: readonly MachineRule[] } = {}): GithubProvider {
  const machines = opts.machines ?? [];

    id: 'github',
    async probe(token) {
      const r = await fetchUser(token);
      if (r.kind === 'integration') {
        throw new IdentityError('unauthorized', 'A GitHub App installation token cannot sign in as a person', 403);
      }
      return r.probe;
    },
    async verify(token) {
      const r = await fetchUser(token);
      return r.kind === 'user' ? r.probe.identity : verifyMachine(token, machines);

  };

```ts
// Per-token verify cache (remote-workspaces §5): fleet-host verifies every
// request, so successes are cached for 5 minutes — revoking a token or removing
// someone from a team takes effect within that window. Keys are SHA-256 of the
// token (the raw token is never a map key). Failures are not cached; concurrent
// verifications of one token share one upstream call.

import { createHash } from 'node:crypto';
import type { Identity, IdentityProvider } from './types.js';

export const VERIFY_TTL_MS = 5 * 60_000;

export function withVerifyCache(
  inner: IdentityProvider,
  opts: { ttlMs?: number; now?: () => number; maxEntries?: number } = {}
): IdentityProvider {
  const ttl = opts.ttlMs ?? VERIFY_TTL_MS;
  const now = opts.now ?? Date.now;
  const max = opts.maxEntries ?? 1000;
  const hits = new Map<string, { identity: Identity; expiresAt: number }>();
  const inflight = new Map<string, Promise<Identity>>();
  const keyOf = (token: string): string => createHash('sha256').update(token).digest('hex');

  return {
    id: inner.id,
    verify(token) {
      const key = keyOf(token);
      const hit = hits.get(key);
      if (hit && hit.expiresAt > now()) return Promise.resolve(hit.identity);
      if (hit) hits.delete(key);
      const pending = inflight.get(key);
      if (pending) return pending;
      const p = inner
        .verify(token)
        .then((identity) => {
          if (hits.size >= max) {
            const oldest = hits.keys().next().value;
            if (oldest !== undefined) hits.delete(oldest);
          }
          hits.set(key, { identity, expiresAt: now() + ttl });
          return identity;
        })
        .finally(() => inflight.delete(key));
      inflight.set(key, p);
      return p;
    }
  };
}

// GitHub OAuth device flow (docs: Authorizing OAuth apps → Device flow). Pure —
// global fetch only. requestDeviceCode once, then pollDeviceToken no faster
// than intervalMs; IdentityService owns the timing. No client secret.

export const GITHUB_DEVICE_CODE_URL = 'https://github.com/login/device/code';
export const GITHUB_TOKEN_URL = 'https://github.com/login/oauth/access_token';
export const GITHUB_DEVICE_PAGE = 'https://github.com/login/device';
/** Minimum for identity (public profile needs no scope), teams and GHCR pulls. */
export const GITHUB_SCOPES: readonly string[] = ['read:org', 'read:packages'];

const GRANT_TYPE = 'urn:ietf:params:oauth:grant-type:device_code';
const SLOW_DOWN_STEP_MS = 5000;

export interface DeviceCode {
  deviceCode: string;
  userCode: string;
  verificationUri: string;
  expiresAt: number;
  intervalMs: number;
}

export type DeviceFlowErrorKind = 'expired' | 'denied' | 'disabled' | 'bad-client' | 'network' | 'unexpected';

/** Messages are user-facing (shown in Settings → Account). */
export class DeviceFlowError extends Error {
  readonly kind: DeviceFlowErrorKind;
  constructor(kind: DeviceFlowErrorKind, message: string) {
    super(message);
    this.name = 'DeviceFlowError';
    this.kind = kind;
  }
}

export type PollResult = { status: 'pending'; intervalMs: number } | { status: 'done'; token: string; scopes: string[] };

async function post(url: string, params: Record<string, string>): Promise<Record<string, unknown>> {
  let res: Response;
  try {
    res = await fetch(url, {
      method: 'POST',
      headers: { Accept: 'application/json', 'Content-Type': 'application/x-www-form-urlencoded', 'User-Agent': 'claude-fleet' },
      body: new URLSearchParams(params).toString()
    });
  } catch (err) {
    throw new DeviceFlowError('network', `Couldn't reach github.com (${(err as Error).name}). Check your network.`);
  }
  let body: unknown = null;
  try {
    body = await res.json();
  } catch {
    /* fall through */
  }
  if (!body || typeof body !== 'object') throw new DeviceFlowError('unexpected', `GitHub answered HTTP ${res.status} without JSON`);
  return body as Record<string, unknown>;
}

function mapError(code: string): DeviceFlowError {
  switch (code) {
    case 'expired_token':
      return new DeviceFlowError('expired', 'The sign-in code expired. Start again.');
    case 'access_denied':
      return new DeviceFlowError('denied', 'Sign-in was cancelled on GitHub.');
    case 'device_flow_disabled':
      return new DeviceFlowError('disabled', 'Device flow is disabled for this OAuth app. Enable it in the app’s GitHub settings.');
    case 'incorrect_client_credentials':
      return new DeviceFlowError('bad-client', 'GitHub does not recognise the configured OAuth client id.');
    default:
      return new DeviceFlowError('unexpected', `GitHub device flow error: ${code}`);
  }
}

function safeVerificationUri(raw: string): string {
  try {
    const u = new URL(raw);
    return u.protocol === 'https:' && u.hostname === 'github.com' ? u.toString() : GITHUB_DEVICE_PAGE;
  } catch {
    return GITHUB_DEVICE_PAGE;
  }
}

export async function requestDeviceCode(clientId: string, now: () => number = Date.now): Promise<DeviceCode> {
  const b = await post(GITHUB_DEVICE_CODE_URL, { client_id: clientId, scope: GITHUB_SCOPES.join(' ') });
  if (typeof b.error === 'string') throw mapError(b.error);
  if (
    typeof b.device_code !== 'string' ||
    typeof b.user_code !== 'string' ||
    typeof b.verification_uri !== 'string' ||
    typeof b.expires_in !== 'number'
  ) {
    throw new DeviceFlowError('unexpected', 'GitHub device code response is missing fields');
  }
  const interval = typeof b.interval === 'number' && b.interval > 0 ? b.interval : 5;
  return {
    deviceCode: b.device_code,
    userCode: b.user_code,
    verificationUri: safeVerificationUri(b.verification_uri),
    expiresAt: now() + b.expires_in * 1000,
    intervalMs: interval * 1000
  };
}

export async function pollDeviceToken(clientId: string, deviceCode: string, intervalMs: number): Promise<PollResult> {
  const b = await post(GITHUB_TOKEN_URL, { client_id: clientId, device_code: deviceCode, grant_type: GRANT_TYPE });
  if (typeof b.access_token === 'string' && b.access_token) {
    const scopes = typeof b.scope === 'string' ? b.scope.split(/[\s,]+/).filter(Boolean) : [];
    return { status: 'done', token: b.access_token, scopes };
  }
  if (b.error === 'authorization_pending') return { status: 'pending', intervalMs };
  if (b.error === 'slow_down') {
    const fromGithub = typeof b.interval === 'number' && b.interval > 0 ? b.interval * 1000 : 0;
    return { status: 'pending', intervalMs: Math.max(fromGithub, intervalMs + SLOW_DOWN_STEP_MS) };
  }
  if (typeof b.error === 'string') throw mapError(b.error);
  throw new DeviceFlowError('unexpected', 'GitHub token response had neither a token nor an error');
}

  vault: IdentityVault;
  clientId(): Promise<string | null>;
  github?: GithubSignInApi;
  now?: () => number;
}

interface Profile {
  identity: Identity;
  scopes: string[];
  sso: SsoHint | null;
  verifiedAt: number;
}
interface Saved {
  token: string;
  profile: Profile;
}
interface Pending {
  clientId: string;
  code: DeviceCode;
  intervalMs: number;
  nextPollAt: number;
  inflight: boolean;
}

export class IdentityNotConfiguredError extends Error {
  constructor() {
    super(`not-configured: ${CLIENT_ID_MISSING}`);
    this.name = 'IdentityNotConfiguredError';
  }
}

export function toAccountSso(sso: SsoHint, clientId: string | null): AccountSso {
  return {
    url: sso.url,
    org: sso.org,
    orgCount: sso.orgIds.length,
    appSettingsUrl: clientId ? `https://github.com/settings/connections/applications/${encodeURIComponent(clientId)}` : null
  };
}

function isProfile(v: unknown): v is Profile {
  if (!v || typeof v !== 'object') return false;
  const p = v as Partial<Profile>;
  const i = p.identity as Partial<Identity> | undefined;
  return !!i && typeof i.login === 'string' && typeof i.id === 'number' && Array.isArray(i.teams) && Array.isArray(p.scopes);
}

function defaultGithub(): GithubSignInApi {
  const provider = createGithubProvider();
  return {
    requestDeviceCode: (clientId) => requestDeviceCode(clientId),
    pollDeviceToken,
    probe: (token) => provider.probe(token)
  };
}

export class IdentityService {
  private readonly vault: IdentityVault;
  private readonly clientId: () => Promise<string | null>;
  private readonly github: GithubSignInApi;
  private readonly now: () => number;
  /** Used only while the vault is unavailable (sign-in lasts this run). */
  private memory: Saved | null = null;
  private pending: Pending | null = null;
  private notice: string | null = null;

  constructor(deps: IdentityServiceDeps) {
    this.vault = deps.vault;
    this.clientId = deps.clientId;
    this.github = deps.github ?? defaultGithub();
    this.now = deps.now ?? Date.now;
  }

  private persisted(): Promise<boolean> {
    return this.vault.isVaultAvailable();
  }

  private async load(): Promise<Saved | null> {
    if (!(await this.persisted())) return this.memory;
    const token = await this.vault.getSecret(GITHUB_IDENTITY_SCOPE, TOKEN_KEY);
    if (!token) return null;
    const raw = await this.vault.getSecret(GITHUB_IDENTITY_SCOPE, PROFILE_KEY);
    let profile: unknown = null;
    try {
      profile = raw ? JSON.parse(raw) : null;
    } catch {
      profile = null;
    }
    return isProfile(profile) ? { token, profile } : null;
  }

  private async save(s: Saved): Promise<void> {
    if (!(await this.persisted())) {
      this.memory = s;
      return;
    }
    await this.vault.setSecret(GITHUB_IDENTITY_SCOPE, TOKEN_KEY, s.token);
    await this.vault.setSecret(GITHUB_IDENTITY_SCOPE, PROFILE_KEY, JSON.stringify(s.profile));
  }

  private async clear(): Promise<void> {
    this.memory = null;
    if (await this.persisted()) await this.vault.deleteAllForWorkspace(GITHUB_IDENTITY_SCOPE);
  }

  private async toStatus(saved: Saved | null): Promise<AccountStatus> {
    const clientId = await this.clientId();
    const p = saved?.profile ?? null;
    return {
      configured: clientId !== null,
      persisted: await this.persisted(),
      signedIn: saved !== null,
      identity: p
        ? {
            provider: 'github',
            login: p.identity.login,
            id: p.identity.id,
            name: p.identity.name,
            displayName: displayName(p.identity),
            avatarUrl: p.identity.avatarUrl,
            teams: p.identity.teams
          }
        : null,
      scopes: p?.scopes ?? [],
      packagesAccess: p ? hasPackagesRead(p.scopes) : false,
      sso: p?.sso ? toAccountSso(p.sso, clientId) : null,
      notice: this.notice
    };
  }

  /** Current account. `refresh` re-verifies with GitHub: a rejected token is
   *  cleared (with a notice); an unreachable GitHub keeps the cached profile. */
  async status(opts: { refresh?: boolean } = {}): Promise<AccountStatus> {
    let saved = await this.load();
    if (saved && opts.refresh) {
      try {
        const probe = await this.github.probe(saved.token);
        saved = { token: saved.token, profile: { ...probe, verifiedAt: this.now() } };
        await this.save(saved);
      } catch (err) {
        if (err instanceof IdentityError && err.kind === 'unauthorized') {
          await this.clear();
          saved = null;
          this.notice = REVOKED_NOTICE;
        }
      }
    }
    return this.toStatus(saved);
  }

  async signInStart(): Promise<SignInStart> {
    const clientId = await this.clientId();
    if (!clientId) throw new IdentityNotConfiguredError();
    const code = await this.github.requestDeviceCode(clientId);
    this.pending = { clientId, code, intervalMs: code.intervalMs, nextPollAt: this.now() + code.intervalMs, inflight: false };
    this.notice = null;
    return { userCode: code.userCode, verificationUri: code.verificationUri, expiresAt: code.expiresAt, intervalMs: code.intervalMs };
  }

  /** One step of the flow. Never polls GitHub faster than its interval, and
   *  at most one request is in flight. */
  async signInPoll(): Promise<SignInPoll> {
    const p = this.pending;
    if (!p) return { state: 'error', message: 'No sign-in in progress.' };
    const now = this.now();
    if (now >= p.code.expiresAt) {
      this.pending = null;
      return { state: 'error', message: 'The sign-in code expired. Start again.' };
    }
    if (p.inflight) return { state: 'pending', intervalMs: p.intervalMs };
    if (now < p.nextPollAt) return { state: 'pending', intervalMs: p.nextPollAt - now };

    p.inflight = true;
    let r: PollResult;
    try {
      r = await this.github.pollDeviceToken(p.clientId, p.code.deviceCode, p.intervalMs);
    } catch (err) {
      if (err instanceof DeviceFlowError && err.kind === 'network') {
        p.nextPollAt = this.now() + p.intervalMs;
        return { state: 'pending', intervalMs: p.intervalMs };
      }
      if (this.pending === p) this.pending = null;
      return { state: 'error', message: (err as Error).message };
    } finally {
      p.inflight = false;
    }
    if (this.pending !== p) return { state: 'error', message: 'Sign-in was cancelled.' };
    if (r.status === 'pending') {
      p.intervalMs = r.intervalMs;
      p.nextPollAt = this.now() + r.intervalMs;
      return { state: 'pending', intervalMs: r.intervalMs };
    }

    this.pending = null;
    let probe: GithubProbe;
    try {
      probe = await this.github.probe(r.token);
    } catch (err) {
      return { state: 'error', message: `Signed in, but reading your GitHub profile failed: ${(err as Error).message}` };
    }
    const scopes = probe.scopes.length > 0 ? probe.scopes : r.scopes;
    const saved: Saved = { token: r.token, profile: { identity: probe.identity, scopes, sso: probe.sso, verifiedAt: this.now() } };
    await this.save(saved);
    return { state: 'done', status: await this.toStatus(saved) };
  }

  signInCancel(): void {
    this.pending = null;
  }

  /** Forget the token on this computer. (Revoking it on GitHub needs the app's
   *  client secret, which a desktop app doesn't have; the UI links the user to
   *  GitHub's Authorized OAuth Apps page instead.) */
  async signOut(): Promise<void> {
    this.pending = null;
    this.notice = null;
    await this.clear();
  }

  /** For loadoutSources.setGithubTokenProvider: the token, only if it can pull
   *  from GHCR. Main process only. */
  async packagesToken(): Promise<string | null> {
    const s = await this.load();
    return s && hasPackagesRead(s.profile.scopes) ? s.token : null;
  }
}

// AccountStatus / SignInStart / SignInPoll only — the token and device code

import type { IpcHandleLike } from '../vaultIpc.js';

export const IDENTITY_CHANNELS = [
  'identity:status',
  'identity:signInStart',
  'identity:signInPoll',
  'identity:signInCancel',
  'identity:signOut'

export interface IdentityIpcApi {
  status(opts?: { refresh?: boolean }): Promise<AccountStatus>;
  signInStart(): Promise<SignInStart>;
  signInPoll(): Promise<SignInPoll>;
  signInCancel(): void;
  signOut(): Promise<void>;
}

export function registerIdentityIpc(ipc: IpcHandleLike, svc: IdentityIpcApi): void {
  ipc.handle('identity:status', (_e, opts: unknown) => {
    const refresh = typeof opts === 'object' && opts !== null && (opts as { refresh?: unknown }).refresh === true;
    return svc.status({ refresh });
  });
  ipc.handle('identity:signInStart', () => svc.signInStart());
  ipc.handle('identity:signInPoll', () => svc.signInPoll());
  ipc.handle('identity:signInCancel', () => {
    svc.signInCancel();
  });
  ipc.handle('identity:signOut', () => svc.signOut());
}

// Pure copy/formatting for Settings → Account (remote-workspaces (b)).
import type { AccountSso } from '../../preload/identityTypes';

const IPC_PREFIX = /^Error invoking remote method '[^']+': (Error: )?/;

export type IdentityUiError = { kind: 'not-configured' | 'other'; message: string };

export function parseIdentityError(err: unknown): IdentityUiError {
  const raw = String((err as Error | undefined)?.message ?? err).replace(IPC_PREFIX, '');
  const m = /^not-configured: ([\s\S]*)$/.exec(raw);
  return m ? { kind: 'not-configured', message: m[1] } : { kind: 'other', message: raw };
}

export interface SsoPrompt {
  text: string;
  url: string | null;
}

export function ssoPrompt(sso: AccountSso | null): SsoPrompt | null {
  if (!sso) return null;
  if (sso.url) {
    return {
      text: `Authorise claude-fleet for ${sso.org ?? 'your organisation'}. Organisations that use SAML single sign-on need this one-time GitHub step before claude-fleet can see your teams there.`,
      url: sso.url
    };
  }
  if (sso.orgCount > 0) {
    const n = sso.orgCount === 1 ? '1 organisation uses' : `${sso.orgCount} organisations use`;
    return {
      text: `${n} SAML single sign-on and haven't authorised claude-fleet yet, so their teams are hidden. Authorising is a one-time GitHub step.`,
      url: sso.appSettingsUrl
    };
  }
  return null;
}

export function countdown(expiresAt: number, now: number): string {
  const s = Math.max(0, Math.ceil((expiresAt - now) / 1000));
  return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, '0')}`;
}

export function packagesNote(signedIn: boolean, packagesAccess: boolean): string | null {
  if (!signedIn) return null;
  return packagesAccess
    ? 'Private ghcr.io loadout sources use this sign-in when they have no token of their own.'
    : 'This sign-in lacks the read:packages scope, so private ghcr.io loadout sources still need their own token. Sign out and sign in again to grant it.';

// sign-out. Self-contained like NotificationsSettings — each action applies at
// once (no batch Save). The token never reaches the renderer; this panel only
// sees AccountStatus.
import { useEffect, useRef, useState } from 'react';
import type { AccountStatus, SignInStart } from '../../../preload';
import { countdown, packagesNote, parseIdentityError, ssoPrompt } from '../accountView';

export function AccountSettings() {
  const [status, setStatus] = useState<AccountStatus | null>(null);
  const [flow, setFlow] = useState<SignInStart | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const [copied, setCopied] = useState(false);
  const [now, setNow] = useState(() => Date.now());
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);

  useEffect(() => {
    window.api.identity
      .status({ refresh: true })
      .then(setStatus)
      .catch((e: unknown) => setError(parseIdentityError(e).message));
    return () => {
      // Closing Settings abandons a half-done sign-in.
      if (timer.current) clearTimeout(timer.current);
      void window.api.identity.signInCancel();
    };
  }, []);

  useEffect(() => {
    if (!flow) return;
    const tick = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(tick);
  }, [flow]);

  function poll(ms: number): void {
    if (timer.current) clearTimeout(timer.current);
    timer.current = setTimeout(() => {
      window.api.identity
        .signInPoll()
        .then((r) => {
          if (r.state === 'pending') poll(r.intervalMs);
          else if (r.state === 'done') {
            setFlow(null);
            setStatus(r.status);
          } else {
            setFlow(null);
            setError(r.message);
          }
        })
        .catch((e: unknown) => {
          setFlow(null);
          setError(parseIdentityError(e).message);
        });
    }, ms);
  }

  async function signIn(): Promise<void> {
    setError(null);
    setBusy(true);
    try {
      const f = await window.api.identity.signInStart();
      setFlow(f);
      setNow(Date.now());
      poll(f.intervalMs);
    } catch (e) {
      setError(parseIdentityError(e).message);
    } finally {
      setBusy(false);
    }
  }

  async function cancel(): Promise<void> {
    if (timer.current) clearTimeout(timer.current);
    setFlow(null);
    await window.api.identity.signInCancel();
  }

  async function signOut(): Promise<void> {
    setBusy(true);
    setError(null);
    try {
      await window.api.identity.signOut();
      setStatus(await window.api.identity.status());
    } catch (e) {
      setError(parseIdentityError(e).message);
    } finally {
      setBusy(false);
    }
  }

  async function copyCode(): Promise<void> {
    if (!flow) return;

    setCopied(true);
    setTimeout(() => setCopied(false), 1500);
  }

  if (!status) {
    return (

      </div>

  const pkg = packagesNote(status.signedIn, status.packagesAccess);
  const who = status.identity;

  return (
    <div className="new-tab account-tab" role="tabpanel">
      <div className="settings-section">
        <div className="settings-section-header">GitHub</div>

        {!status.configured && (
          <p className="setting-desc">
            GitHub sign-in isn't configured in this build. Set <code>CLAUDE_FLEET_GITHUB_CLIENT_ID</code> or{' '}
            <code>identity.github.clientId</code> in config.json.
          </p>
        )}

        {status.signedIn && who && (
          <div className="account-card">
            {who.avatarUrl && <img className="account-avatar" src={who.avatarUrl} alt="" width={40} height={40} />}
            <div className="account-who">
              <div className="account-name">{who.displayName}</div>
              <div className="account-login">@{who.login}</div>
            </div>
            <button type="button" className="btn" onClick={() => void signOut()} disabled={busy}>
              Sign out
            </button>
          </div>
        )}
        {status.signedIn && who && who.teams.length > 0 && <p className="setting-desc">Teams: {who.teams.join(', ')}</p>}

        {status.configured && !status.signedIn && !flow && (
          <>
            <button type="button" className="btn primary" onClick={() => void signIn()} disabled={busy}>
              Sign in with GitHub
            </button>
            <p className="setting-desc">
              Uses claude-fleet's own GitHub app (separate from the gh CLI). It asks for read:org (your teams) and
              read:packages (private ghcr.io loadouts).
            </p>
          </>
        )}

        {flow && (
          <div className="device-flow">
            <p className="setting-desc">Enter this code on GitHub:</p>
            <div className="device-code" aria-label="Device code">

### Identity
GitHub sign-in for the desktop (remote-workspaces sub-project (b), `src/main/identity/`). The OAuth token lives in the host-only vault scope `identity:github` (§7 *Vault layout*) and **never crosses IPC**. The renderer sees only `AccountStatus` (`src/preload/identityTypes.ts`): `{ configured, persisted, signedIn, identity: { provider, login, id, name, displayName, avatarUrl, teams } | null, scopes, packagesAccess, sso: { url, org, orgCount, appSettingsUrl } | null, notice }`.

It starts the GitHub OAuth **device flow** (`POST https://github.com/login/device/code`, scopes `read:org read:packages`) with claude-fleet's own OAuth app. The device code stays in main.
